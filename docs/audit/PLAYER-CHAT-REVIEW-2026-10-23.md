# 玩家聊天交互复审 · 2026-10-23

审查基线：`44413a0`。范围为这次新增的输入法保护、剧情滚动、桌面分栏、状态变化浮层和已读红点。按正确性、可读性、架构、安全与性能检查，同时核对用户的交互规范；不扩展后台、接口或计费规则。

## 发现并修复的问题

| 级别 | 原触发条件与影响 | 修复与回归证据 |
| --- | --- | --- |
| P2 | 悬停一个短变化浮层 700ms，就会清除该板块红点，即使实际板块内容仍很长、尚未阅读；快速切标签也可提前确认已读。 | 浮层仅预览变化。实际板块可见、已到末尾且没有未展开记录时，停留 700ms 后才确认阅读；浮层覆盖、隐藏或拖动期间不确认。补测短浮层、长板块、快速切换、折叠记录、新回合与账户持久化。 |
| P2 | 键盘进入可滚动浮层后按 Escape，浮层被卸载，焦点落到 body。 | 记录实际触发控件，关闭时恢复焦点；保留外部点击与失焦关闭。新增真实 focus/keydown 回归。 |
| P2 | 分隔握柄中部按下后，首次 pointermove 会把握柄内偏移算进比例，示例中无位移就从 50% 变为 50.7%；窗口尺寸变化也没有取消旧坐标系下的拖动。 | 保存按下位置偏移，零位移不改变比例；窗口 resize 取消拖动并恢复原比例。右栏拖动期间 inert，遮罩仍保留。新增偏移、resize 取消测试，原 Escape、双击、82% 收起与键盘调宽测试通过。 |
| P2 | 手机隐藏剧情期间新增内容，切回剧情但没有再收到 token 时，没有重新计算距离，可能不显示“跳至最新”。字号、分栏等布局变化也缺少测量。 | 把视图切换加入同步，返回时保留正文位置；通过节点绑定、ResizeObserver 与 resize 监听重新测量，测量不滚动。补测隐藏返回、布局变化、空正文延后挂载和监听清理。 |
| P2 | 行动按钮上的空格键冒泡到正文，被当作主动滚动，导致键盘选择行动后失去跟随。 | 区分控件激活与翻页滚动；空格激活按钮、编辑输入和已处理事件不会误触中止。新增键盘激活回归。 |

## 要求核对

| 用户要求 | 审查结论 |
| --- | --- |
| 中文选字时 isComposing / keyCode 229 不发送；结束后 500ms 内拦截 Enter | 共享输入键盘逻辑覆盖剧情、助手和初始化；测试覆盖 499ms 拦截、500ms 放行，并保留 Ctrl / ⌘ + Enter 发送。候选选字交给输入法处理。 |
| 40px 内跟随、主动滚动暂停、超过 120px 出现跳转 | 阈值及边界测试通过；wheel、touch、翻页键暂停，主动到达底部或点击跳转恢复；历史阅读和隐藏视图保留位置。 |
| 单层描边、内部按钮无边框、悬停底色、inset 阴影 | 按现有 CSS 静态核对符合；尺寸不依赖边框或悬停变换。输入不使用 outline，按钮与链接保留键盘焦点。实际视觉待浏览器验收。 |
| 外圆角 = 内圆角 + 内边距 | 主聊天输入为 14px = 6px + 8px，使用共享 CSS 变量。 |
| 拖动遮罩、Esc 撤销、双击 50/50、超过 82% 收起 | 逻辑与回归通过；拖动还会屏蔽右栏键盘操作，窗口变化取消手势，小屏仍使用四入口。 |
| 长文件名中间省略、保留后缀 | 当前玩家聊天没有附件或文件名展示，此项无适用位置。没有添加无消费者的组件。 |
| 每回合变化 tooltip、各板块完整浏览后清除红点 | 使用真实已保存回合的获得、消耗、前后变化及事件；按回合分组。已读按账户、存档保存；全部板块读完才清除总入口红点，新回合仅提醒发生变化的板块。修正了原版过早确认的问题。 |
| 延续此前统一视觉与反馈规范 | 本轮沿用既有主题、暗色字重、数字等宽、90ms 流式渐清晰、Grid 折叠、复制反馈与减少动态效果，没有增加依赖或替换组件体系。 |
