# 故事评论区

每个已上架且服务模型启用的故事拥有独立评论区。入口位于故事卡片、角色选择页的“故事评论”，以及游玩页顶部的评论图标。

本机《绍宋》入口：http://localhost:5173/play/stories/1546/comments 。其他部署按本机故事编号访问`/play/stories/{id}/comments`。

## 行为

- 游客可阅读，发表评论与删除需要本人登录。服务器部署沿用玩家账户验证要求。
- 最多2000字纯文本，自动去除首尾空白；不渲染HTML或Markdown。默认每页20条，最新优先，点击加载更早评论。
- 普通玩家只能删除本人评论，管理员可删除任何当前公开故事下的评论。删除操作先行内确认，失败时保留评论并允许重试。
- 发布失败保留草稿，草稿按账户和故事分别保存在当前浏览器。支持Ctrl / ⌘ + Enter，中文输入法选字期间不会误发。
- 每个账户每分钟最多发布5条。不消耗玩家积分，不调用模型，也不把评论写进剧情、原文资料或存档。
- 故事下架、停用或模型服务关闭后，评论列表和写入入口不可访问。

## 接口与数据库

- `GET /api/player/stories/{id}/comments?before={comment_id}&limit=20`：返回`items`和`next_cursor`；单页最多50条。
- `POST /api/player/stories/{id}/comments`，正文`{"content":"评论内容"}`。
- `POST /api/player/stories/{id}/comments/{comment_id}/delete`。

响应仅含评论编号、公开作者名称、正文、时间和服务端计算的删除权限，不暴露账户邮箱、账户编号或存档内容。查询、删除均绑定故事编号。

数据库升级使用migration 108：`player_story_comments`及故事游标、作者索引。部署升级前运行`python -m platform_app.migrate up`；本机已应用。

## 验证

真实PostgreSQL集成测试覆盖游客读写边界、作者与管理员删除权限、空白及超长拒绝、下架隔离、跨故事隔离、游标分页和频率限制。前端测试覆盖公开入口、登录返回、纯文本显示、草稿、失败重试、删除确认、输入法与重复点击。

本机真实HTTP完成临时故事的发布、读取、删除流程，随后清理临时故事与评论。未在正式故事中留下验收评论。Work设置关闭浏览器访问，未进行页面视觉验收。
