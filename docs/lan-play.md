# 局域网游玩

Windows 上使用项目已有的 Python 环境、前端依赖和 PostgreSQL：

```powershell
.\scripts\dev.ps1 status
.\scripts\lan.ps1 start
```

启动脚本先构建前端，再由同一个 FastAPI 服务提供玩家页面、登录、API 和 SSE，默认端口为 7860。启动完成会打印当前网卡的玩家地址；手机或其他电脑连接同一局域网后打开该地址的 `/play`。直接打开存档链接及刷新也支持。

端口已占用时脚本会停止启动，不会杀掉现有服务。先结束原来的本机后端，再启动局域网服务；也可指定空闲端口 `-Port 7861`。已构建且源码未变时可用 `-SkipBuild`。

```powershell
.\scripts\lan.ps1 status
.\scripts\lan.ps1 stop
```

停止命令只处理该脚本记录并核对身份的进程。数据库及原有存档继续保留。运行日志和进程记录位于被 Git 忽略的 `.dev-logs/lan/`。

局域网访问沿用现有账户、注册限制、积分和权限。其他设备需要登录，不能使用仅面向本机回环请求的默认账户免登录入口；模型凭据仍由服务端管理。其他设备无法连接时检查电脑防火墙是否允许该服务的 TCP 端口，以及无线网络是否启用了设备隔离。
