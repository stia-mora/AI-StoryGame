# 本片可复用经验

1. 真正的玩家反馈可以只截取已保存行动与正文中的一小段：本片 30–34 秒将输入框、保存行动和剧情回应放在同一桌面，补足玩法闭环；同时明确保存回合来源，避免把未执行选项伪装成已生成结果。
2. 道具动画的事件应服务于调查：检查照片时移动照片，查地图时扫动手电，结尾移开路线纸让观众进入街景。低分辨率运动门禁由红灯改善至黄灯，保留产品内容的阅读停顿。
3. 浏览器对缩放截图的冷绘制与重复绘制可能有少量像素差。先在启动阶段把截图采样到实际展示尺寸并冻结像素，再以 1:1 绘制，产品两镜的重复绘制检查由失败变为逐像素一致。核对依据保留在 `qa-retest/qa.json`，最终全片复测保留在 `qa/`。
4. Windows 上 QA 脚本的默认文本编码可能无法保存勾选符号；运行时设置 `PYTHONUTF8=1` 即可，无需改动安装的技能脚本。
