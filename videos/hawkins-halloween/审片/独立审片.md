# 独立审片

审片对象：`renders/hawkins-halloween-c-v2.mp4`，40.000 秒，1080 × 1920，30 fps。审片人未参与制作，未阅读制作源码；依据 MP4 解码帧进行判断。先按每秒一帧检查全片，再检查主要切点及全分辨率关键帧；26–34 秒另按每 0.5 秒一帧复核。v1 与 v2 的完整解码视频 MD5 均为 `8b6b05aa2f7eb84ce49429e5fa0c211a`，所以复用了 v1 的图像检查，音轨以 v2 单独测量。

仅列 P0/P1 问题，不评分。未发现 P0；有以下两项 P1。

## P1 — 结尾没有可执行的游玩入口

- **时间：00:37.000–00:40.000。**
- **可见事实：**结尾显示“故事之间”“进入万圣夜”“互动同人故事”，没有 `/play`、网址、二维码，也没有“点击链接／打开故事之间后进入……”等入口动作说明。00:38.000 的完整画面可直接复核，直至最后一帧仍无入口信息。
- **影响：**独立播放的宣传片给出了情绪性的邀请，但观众无法仅凭成片知道到哪里开始游玩；这直接影响导流目的。
- **建议：**在现有结尾上加入经确认可用的入口路径和明确动作，例如“进入故事之间 → /play → 选择《万圣夜，别松手》”，并让这条信息在结尾稳定保留。若发布载体已绑定入口，至少明确“点击下方链接开始”。
- **证据：**`output/independent-film-review/frame-38.000.png`。

## P1 — 玩法段没有完成一个动作，悬念在功能展示处停住

- **时间：00:26.000–00:34.000。**
- **可见事实：**00:26.000–00:30.000 是四项长选项的界面，C 项出现边框高亮后继续保留；未展示该选择触发的故事内容。00:30.000–00:34.000 切到“也能自由行动”，指针进入输入框，但框内始终是“描述你的行动、目标，或写一段对话……”占位文字，没有输入、提交或后续反馈。每 0.5 秒的解码序列可复核这一状态。
- **影响：**“刚才有人叫我／这次你来决定”的悬念已经建立，但紧接的 8 秒只证明有选项和输入框，没有让观众看到自己能怎样介入这件事。这里形成两张功能说明页的观看感，削弱了从悬念到实际游玩的连接。
- **建议：**用现有时长展示一个最短闭环：聚焦“问 Will 是否还好”这一项或输入一条与呼唤有关的行动，出现提交反馈，再露出一句新的故事反应；无需增加完整教程或延长片长。
- **证据：**`output/independent-film-review/ui-half-second.png`、`frame-27.000.png`、`frame-31.000.png`。

## 检查边界与客观结果

- 全片解码成功，共 1200 帧；按 `blackdetect=d=0.1:pix_th=0.10` 扫描未报告持续黑帧。每秒缩略图及切点抽查未见空白画面。
- 主字幕、片名和主要地图／对讲机道具的辨识，未形成其他 P0/P1 问题。桌面镜头有道具与镜头运动；上述第二项针对的是玩法展示的动作闭环，不把全片判为静态幻灯片。
- v2 音轨仅做测量，未实听：综合响度约 **-16.4 LUFS**，真峰值约 **-1.7 dBFS**；低于 -45 dB 的末尾区间约为 **00:39.891–00:40.000**。这些测量不能证明配乐、对白或音效的主观听感与混音清晰度。
